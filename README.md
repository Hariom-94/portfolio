# Video Editor Portfolio — Cut/TC

A single-page portfolio for a video editor, built around a "timeline ruler"
navigation bar and NLE-track motif (V1/V2/V3/V4/A1). Includes:

- **Hero** with an animated total-views counter (defaults to 37,517,000,
  computed from the client data below — see `src/data.js`)
- **Client channels rail** — 8 creator channels with avatar, subs, and
  views-on-edits
- **Featured reel** — 4 long-form flagship edits, playable with **Mux Player**
- **Before / after the grade** — a synced, draggable comparison slider
  (`react-compare-slider`) showing raw vs. graded footage
- **Full cut list** — 48-item filterable grid (45+ edits), thumbnails
  auto-generated by Mux, each opens a Mux Player modal on click
- **Contact form** wired to **EmailJS**

Stack: React 19 + Vite, Tailwind CSS v4, Framer Motion, `@mux/mux-player-react`,
`@emailjs/browser`, `react-compare-slider`, `lucide-react`.

## Run it

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```

## 1. Replace the placeholder content

Everything you need to personalize lives in **`src/data.js`**:

- `clientChannels` — real channel names, handles, subscriber counts, and view
  totals. The hero's 37.5M counter is *derived* from this array
  (`TOTAL_VIEWS`), so just update the numbers here and the hero updates
  itself.
- `featuredReels` — your 4 long-form pieces. Set `playbackId` to a real Mux
  asset id per video (see below).
- `portfolioItems` — the 45+ grid entries (currently auto-generated from
  `titleBank`). Replace with your real edit list, or keep the structure and
  swap in real titles/clients/durations/`playbackId`s.

Avatars currently use `ui-avatars.com` to generate initials on the fly.
Swap the `src` in `src/components/ClientChannels.jsx` for real client
profile photos (upload them to `public/` or your CDN) whenever you have them.

## 2. Connect Mux

Every player on the page points at a public Mux demo asset
(`DEMO_PLAYBACK_ID` in `src/data.js`) so the site works immediately. To show
your real edits:

1. Upload each video in the Mux dashboard (dashboard.mux.com), or via the
   Mux API, and copy its **Playback ID**.
2. Paste that ID into the matching item's `playbackId` field in
   `src/data.js`.

`@mux/mux-player-react` handles adaptive streaming, thumbnails and analytics
automatically — no extra config needed beyond the playback ID.

**Grid thumbnails** come from Mux's image API
(`image.mux.com/{playbackId}/thumbnail.jpg`), which pulls a real frame
straight out of the video — no separate image upload needed. Once every
`portfolioItems` entry has its own real `playbackId`, each tile will show a
distinct thumbnail automatically. Right now they all share one demo asset,
so `thumbTime` (seconds into the clip) is staggered per item just so the
placeholder grid doesn't look identical tile to tile.

## 3. Before / after grade slider

`src/components/ColorGradeCompare.jsx` uses `react-compare-slider` with two
synced `<video>` elements — plain HTML5 video, not Mux Player, since the
slider needs direct control over two elements painting in lockstep. It
currently plays one public-domain sample clip twice with different CSS
`filter` values to *simulate* a grade until you swap in your own footage.

To use your real before/after:

1. Export the same shot twice — once ungraded, once with your final grade —
   as two video files of identical length.
2. Replace the single `SRC` constant with two constants (e.g. `RAW_SRC` /
   `GRADED_SRC`) and point each `<video>`'s `src` at the matching file.
3. Delete the `style={{ filter: ... }}` lines — you don't need CSS filters
   once you have two real exports.

## 4. Connect EmailJS

The contact form (`src/components/Contact.jsx`) calls `emailjs.sendForm`.
To make it actually send email:

1. Create a free account at emailjs.com.
2. Add an **Email Service** (e.g. Gmail) — note the **Service ID**.
3. Create an **Email Template** with variables matching the form's field
   `name` attributes: `from_name`, `reply_to`, `project_type`, `channel_url`,
   `message`. Note the **Template ID**.
4. Copy your **Public Key** from Account -> API Keys.
5. In `src/components/Contact.jsx`, set:

   ```js
   const EMAILJS_SERVICE_ID = "your_service_id";
   const EMAILJS_TEMPLATE_ID = "your_template_id";
   const EMAILJS_PUBLIC_KEY = "your_public_key";
   ```

Until these are set, the form shows a friendly inline message instead of
silently failing.

## 5. Customize the look

Design tokens (colors, fonts) are centralized in `src/index.css` under the
`@theme` block — change `--color-amber`, `--color-teal`, fonts, etc. there
and they propagate everywhere as Tailwind utilities (`text-amber`,
`font-display`, and so on).

## Notes

- The timeline ruler at the top tracks real scroll position and jumps to
  sections when you click a track tag (V1/V2/V3/V4/A1).
- The grid and rail are keyboard- and screen-reader-usable; focus states use
  a visible amber outline; `prefers-reduced-motion` is respected.
- Large bundle size on build is expected — `@mux/mux-player-react` and
  `framer-motion` are sizeable. Fine for a portfolio site; code-split later
  if you add more heavy libraries.
